2. VERSION 1.0.1 UPDATE DETAILS
--------------------------------------------------------------------------------

A. Vanilla `/locate region <region_id>` Command Integration
   - Location: `common/src/main/java/com/regionalapi/command/LocateRegionCommand.java`
   - Injected directly into vanilla Brigadier `/locate` command tree as a 
     subcommand (`/locate region`).
   - Auto-Completion: Provides dynamic suggestions for all registered region IDs 
     registered in `RegionRegistry`.
   - Dual-Path Spatial Discovery:
     * Unique Regions (`isUnique == true`): Instantaneous sub-millisecond lookup 
       (under 0.05 ms) utilizing the pre-indexed 2D spatial QuadTree.
     * Procedural Voronoi Regions: High-speed expanding concentric square-ring 
       search across grid cells up to 100 cells (~51,200 blocks radius) with 
       exact mathematical dominance verification.
     * Standing Check: Immediately detects if the command sender is already 
       inside the target region (distance 0).
   - Vanilla UI Feedback: Formats green clickable chat coordinates (`[X, ~, Z]`) 
     configured with `ClickEvent.SUGGEST_COMMAND` for `/tp @s X ~ Z` and distance 
     in blocks.
   - Cross-Loader Registration:
     * NeoForge: Registered via `RegisterCommandsEvent`.
     * Fabric: Registered via `CommandRegistrationCallback.EVENT`.
   - Localization: Added localized translation keys and fallback strings in 
     `assets/regionalapi/lang/en_us.json`.

B. Vanilla-Like F3 Debug Screen Overlay (`Region:` above `Biome:`)
   - Location: `common/src/main/java/com/regionalapi/mixin/client/MixinDebugScreenOverlay.java`
   - Injected into `DebugScreenOverlay#getGameInformation()` via SpongePowered 
     Mixin on the return value.
   - Behavior: Scans the left-side text lines for the `"Biome:"` entry and inserts 
     `"Region: <region_id>"` immediately at that index. This shifts `"Biome:"` 
     down by 1, placing `"Region:"` directly above `"Biome:"`.
   - Mod Compatibility:
     * NeoForge mods utilizing `CustomizeGuiOverlayEvent.DebugScreenText` 
       automatically receive `"Region:"` inside `event.getLeft()`.
     * Fabric mods wrapping or inspecting `getGameInformation()` naturally 
       inherit the line.
   - Side Isolation: Registered under `"client": [ "client.MixinDebugScreenOverlay" ]` 
     in `regionalapi.mixins.json` to guarantee dedicated servers never load 
     client GUI classes.

C. Authoritative Client-Server Region Synchronization
   - Location: `common/src/main/java/com/regionalapi/network/ClientboundSyncPlayerRegionPacket.java`
   - S2C CustomPacketPayload: Transmits the active `ResourceLocation` region ID 
     to the client whenever a player crosses a region border or logs into a server.
   - Location: `common/src/main/java/com/regionalapi/client/ClientRegionTracker.java`
     * Singleplayer: Queries integrated server in real time based on camera position.
     * Multiplayer: Displays the authoritative synced region ID received from 
       the server, ensuring 100% accuracy on dedicated servers.
   - SPI Parity Updates:
     * Added `sendSyncPlayerRegionPacket(ServerPlayer, ResourceLocation)` to 
       `IPlatformHelper`.
     * Implemented in `NeoForgePlatformHelper` via `PacketDistributor.sendToPlayer`.
     * Implemented in `FabricPlatformHelper` via `ServerPlayNetworking.send`.
     * Dispatched in `CommonRegionMovementTracker#checkAndFirePlayerRegionTransition`.

D. Build Versioning Integrity & Distribution
   - Enforced rule: Every release build must increment `mod_version` in 
     `gradle.properties` (never rebuild/overwrite identical versions).
   - Updated root `build.gradle` `copyBuildJars` task to copy output JARs to both 
     `D:\RegionalAPI\BuildVersion\` and `D:\RegionalAPI\BuildVersion\1.21.1\`.
   - Preserved all previous historical JARs (`1.0.0`) intact.

3. VERSION 1.0.2 UPDATE DETAILS
--------------------------------------------------------------------------------

A. Full Minecraft Forge 1.21.1 Support (`:forge` Subproject)
   - Created standalone adapter module: `D:\RegionalAPI\RegionalApiMods\forge\`.
   - Build Toolchain: Configured with `net.minecraftforge.gradle` version 
     `[6.0.24, 6.2)` and Minecraft Forge `1.21.1-52.1.20`.
   - Mapping: Official Mojang Mappings (Mojmap) with Java 21 compilation.
   - Configuration files:
     * `forge/build.gradle`: Manages Forge dependencies and pulls shared code 
       from `:common`.
     * `forge/src/main/resources/META-INF/mods.toml`: Standard Forge mod metadata 
       declaring dependency range `[52.1.20,)` and mixin `regionalapi.mixins.json`.
     * `forge/src/main/resources/META-INF/services/com.regionalapi.platform.IPlatformHelper`: 
       SPI binding for Forge.

B. Forge Platform Adapter & Networking Implementation
   - Location: `forge/src/main/java/com/regionalapi/forge/ForgePlatformHelper.java`
     * Implements `isModLoaded` via `ModList.get().isLoaded(modId)`.
     * Implements `sendSyncSeedPacket` & `sendSyncPlayerRegionPacket` via Forge's 
       `PacketDistributor.PLAYER.with(player).send(new ClientboundCustomPayloadPacket(...))`.
     * Implements `postPlayerRegionEnter` and `postEntitySpawnInRegion` via 
       `MinecraftForge.EVENT_BUS.post(...)`.
   - Location: `forge/src/main/java/com/regionalapi/api/RegionEvent.java`
     * Exposes `PlayerEnterRegionEvent` and `@Cancelable EntitySpawnInRegionEvent` 
       extending `net.minecraftforge.eventbus.api.Event` for downstream Forge mods.
   - Location: `forge/src/main/java/com/regionalapi/forge/RegionalForgeMod.java`
     * Entrypoint marked with `@Mod("regionalapi")`.
     * Registers network payloads using Forge's modern `ChannelBuilder.payloadChannel()` 
       API with `.addMain(...)` for thread-safe packet dispatch.
   - Location: `forge/src/main/java/com/regionalapi/forge/RegionForgeGameplayListeners.java`
     * Hooks Forge events: `ServerAboutToStartEvent`, `ServerStoppedEvent`, 
       `RegisterCommandsEvent`, `ChunkEvent.Unload`, `PlayerLoggedInEvent`, 
       `EntityEvent.EnteringSection`, `TickEvent.PlayerTickEvent.Post`, and 
       `MobSpawnEvent.FinalizeSpawn`.

C. Root Multi-Loader Build Orchestration
   - Updated `settings.gradle` to include `:forge` alongside `:common`, 
     `:neoforge`, and `:fabric`.
   - Updated root `build.gradle` `copyBuildJars` to depend on `:neoforge:build`, 
     `:fabric:build`, and `:forge:build`.
   - Successfully compiled and generated:
     * `regionalapi-fabric-1.0.2.jar`
     * `regionalapi-neoforge-1.0.2.jar`
     * `regionalapi-forge-1.0.2.jar`
