================================================================================
REGIONALAPI CHANGELOG: VERSION 1.0.0 -> 1.0.11
================================================================================
Target: Minecraft 1.21.1 (Java 21) | Fabric, NeoForge, Forge

--- [VERSION 1.0.1] ---
* ADDED: Vanilla command integration for `/locate region <region_id>` with dynamic auto-completion suggestions.
* ADDED: Instantaneous QuadTree lookup for unique regions and expanding ring Voronoi cell search for standard regions.
* ADDED: Green clickable chat coordinates suggesting `/tp @s X ~ Z` with block distance calculation.
* ADDED: F3 debug screen overlay displaying `Region: <id>` placed directly above `Biome:`.
* ADDED: S2C network payload `ClientboundSyncPlayerRegionPacket` for authoritative multiplayer region sync.
* ADDED: Client-side region tracking in `ClientRegionTracker`.
* ADDED: English localization and fallback strings in `en_us.json`.
* ENFORCED: Mandatory build version increment policy preserving all previous release artifacts.

--- [VERSION 1.0.2] ---
* ADDED: Full native support for Minecraft Forge 1.21.1 (`:forge` subproject) with ForgeGradle 6.0 (`net.minecraftforge:forge:1.21.1-52.1.20`).
* ADDED: `ForgePlatformHelper` implementing Java SPI with Forge `PacketDistributor.PLAYER.with(player).send(...)`.
* ADDED: Forge event bus integration with `RegionEvent.PlayerEnterRegionEvent` and `@Cancelable EntitySpawnInRegionEvent`.
* ADDED: Forge networking using modern `ChannelBuilder.payloadChannel()` API.
* ADDED: `RegionForgeGameplayListeners` handling Forge server lifecycle, player login, chunk unload, and tick events.
* UPDATED: Root Gradle orchestration (`copyBuildJars`) to compile Fabric, NeoForge, and Forge simultaneously.

--- [VERSION 1.0.3] ---
* ADDED: Dynamic Voronoi grid cell scale in `VoronoiEngine2D` automatically computed from maximum registered region weight (`regionWeight`).
* ADDED: Support for macro-scale non-unique repeating regions (e.g. 10,000+ to 16,000+ blocks per cell) eliminating rapid 200–512 block border swapping.
* ADDED: Dynamic cell center (`cellBaseX`, `cellBaseZ`) and symmetrical jitter mask calculation based on active cell scale.
* ADDED: Configuration manager `RegionalApiConfig` and automatic creation/loading of `regionalapi.json` with `voronoiCellShift` (range 7–13, or 0 for auto), `generationMode`, and `maxFiniteRadiusBlocks`.
* ADDED: Public developer facade methods in `RegionalApi` for `getVoronoiCellShift()`, `setVoronoiCellShift(int)`, `getVoronoiCellSizeQuarts()`, `getVoronoiCellSizeBlocks()`, and `isAutoComputeCellShift()`.
* UPDATED: `LocateRegionCommand` to adaptively search according to the dynamic Voronoi cell scale.
* UPDATED: `IPlatformHelper` with `getConfigDirectory()` implemented with 100% parity across Fabric, NeoForge, and Forge.

--- [VERSION 1.0.4] ---
* FIXED: Resolved transient region flip/flicker where crossing a chunk boundary momentarily registered an adjacent region (Region C) before snapping back to the correct region (Region A).
* FIXED: `CommonRegionMovementTracker.onPlayerEnterChunk` now strictly derives chunk and quadrant coordinates from the player's true current block coordinates (`player.getBlockX()`, `player.getBlockZ()`) as the single source of truth, preventing desynchronization with `EntityEvent.EnteringSection`.
* FIXED: `RegionGameplayListeners` (NeoForge) and `RegionForgeGameplayListeners` (Forge) now synchronize chunk coordinates to the player's true position on `EnteringSection`.
* FIXED: `ClientboundSyncRegionalSeedPacket` now properly initializes client-side `ThreadLocalRegionCache.setActiveWorldSeed()` upon receiving the packet in multiplayer.
* FIXED: `MixinChunkSerializer.read` now validates chunk NBT against active runtime Voronoi mathematics, rejecting outdated/stale serialized region data from prior configuration scales.

--- [VERSION 1.0.5] ---
* UNIFIED: Synchronized deterministic salted regional seed across server and client (`ClientboundSyncRegionalSeedPacket.computeSaltedRegionalSeed()`), eliminating singleplayer seed mutation and multiplayer desynchronization.
* ADDED: Lock-free atomic cache epoch invalidation (`CACHE_EPOCH`) in `ThreadLocalRegionCache`, ensuring instant cache eviction across all worker and render threads whenever world parameters, seed, or Voronoi scale change.
* FIXED: `MixinChunkSerializer.read` now conducts comprehensive full-chunk slot validation against `ThreadLocalRegionCache` and immediately auto-heals stale NBT with fresh Voronoi data.
* FIXED: Thread-safe read path in `RegionalApi.getRegionRawId()` for Client Render Thread queries, preventing non-thread-safe map mutation on the integrated server.
* FIXED: F3 debug overlay in `ClientRegionTracker` now targets the exact player block position (`minecraft.player.blockPosition()`), eliminating camera-vs-feet border discrepancies.
* FIXED: Bounded Laguerre power distance weight bias in `VoronoiEngine2D` to prevent radical axis drift outside the 3x3 neighborhood, preserving cell convexity across macro weights.
* FIXED: `UniqueRegionQuadTree` dominance resolution, ensuring unique regions reliably override background Voronoi tessellation within their defined weight radius.

--- [VERSION 1.0.6] ---
* FIXED: Resolved dual-layer region desynchronization where entering a new chunk briefly displayed an incorrect region (e.g., Galar) on F3 before snapping to the correct region (e.g., Johto).
* ADDED: Authoritative seed locking (`ThreadLocalRegionCache.setAuthoritativeRegionalSeed()`) and seed guard protection in `ThreadLocalRegionCache.setActiveWorldSeed()`. External callers and third-party mods passing raw unsalted seeds (such as `context.seed()` during structure generation) can no longer corrupt the global active regional seed mid-session.
* ADDED: Clean lifecycle reset (`ThreadLocalRegionCache.resetSeed()`) on server stop and client disconnect across Fabric, NeoForge, and Forge adapters.
* FIXED: Fallback handling in `ClientRegionTracker.getDebugRegionString()` so fallback Wilds gracefully defer to authoritative server-synced player region (`currentRegionId`).
* ENFORCED: 100% mathematical Voronoi parity and zero-GC performance across all worker threads, server threads, and client render threads.

--- [VERSION 1.0.7] ---
* FIXED (CRITICAL): Unified mixin refmap configuration (`regionalapi.refmap.json`). Replaced hardcoded loader-specific refmap reference in `regionalapi.mixins.json` and established standard refmap generation/packaging across NeoForge, Fabric, and Forge.
* FIXED (CRITICAL): SpongePowered Mixin application failure on NeoForge (`MixinChunkAccess`), resolving the bug where `ChunkAccess instanceof IRegionChunkData` evaluated to false and caused whole-world fallback to `regionalapi:wilds` or mid-chunk quart-level border hopping.
* FIXED (CRITICAL): Corrected server lifecycle timing on NeoForge and Forge. Migrated `onServerAboutToStart` (`ServerAboutToStartEvent`) to `onServerStarting` (`ServerStartingEvent`), ensuring `server.overworld()` is fully loaded and non-null when initializing `UniqueRegionSavedData`.
* FIXED (CRITICAL): Removed intrusive `onFinalizeMobSpawn` listener from `RegionGameplayListeners` (NeoForge) and `RegionForgeGameplayListeners` (Forge). Prevents `event.setSpawnCancelled(true)` from discarding spawned entities via `mob.discard()`, fixing entity and Pokémon spawning mechanics (e.g. Cobblemon).
* SYNCHRONIZED: Full 1:1 multi-loader parity between Fabric, NeoForge, and Forge event handling by delegating player chunk transitions and tick polling exclusively to `MixinServerPlayer` and `PlayerLoggedInEvent`.

--- [VERSION 1.0.8] ---
* FIXED (CRITICAL): Resolved NeoForge and Forge spawn-chunk region fallback race condition where `ServerStartingEvent` fired after `loadLevel()` and `prepareLevels()`, causing initial spawn chunks to evaluate while `RegionRegistry.isFrozen()` was `false` and get stamped as `regionalapi:wilds` (`0`).
* ADDED: Two-phase server lifecycle across all loaders (`:neoforge`, `:fabric`, `:forge`): Phase 1 (`ServerAboutToStartEvent` on NeoForge/Forge, `ServerLifecycleEvents.SERVER_STARTING` on Fabric) freezes `RegionRegistry` and locks the authoritative salted regional seed BEFORE `loadLevel()`; Phase 2 (`ServerStartingEvent` on NeoForge/Forge, `ServerLifecycleEvents.SERVER_STARTED` on Fabric) synchronizes and persists `UniqueRegionSavedData` once `server.overworld()` is initialized.
* ADDED: O(1) epoch validation (`regional$populatedEpoch` vs `ThreadLocalRegionCache.getCurrentEpoch()`) in `MixinChunkAccess` (`IRegionChunkData`) and pre-freeze guards in `ChunkRegionAttachment`, `MixinChunkSerializer`, and `ThreadLocalRegionCache`, guaranteeing uninitialized/pre-freeze evaluations can never poison chunk memory or ring buffers and any epoch increment atomically invalidates stale in-memory chunk attachments.

--- [VERSION 1.0.9] ---
* FIXED (CRITICAL): Enforced strict single-region per chunk homogeneity (`1 Chunk = Max 1 Region`). Resolved the bug where Voronoi boundaries crossing a 16x16 chunk subdivided the chunk into 2 or more regions at `QuartPos` (`4x4`) resolution.
* UPDATED: `VoronoiEngine2D.evaluateRegionAtQuart` now quantizes horizontal coordinates to the canonical center `QuartPos` of the containing 16x16 chunk (`sampleQuartX = (quartX & ~3) + 2`, `sampleQuartZ = (quartZ & ~3) + 2`), and `evaluateChunkRegions` performs a single evaluation per chunk at `(chunkX << 2) + 2, (chunkZ << 2) + 2`.
* OPTIMIZED: `ThreadLocalRegionCache`, `MixinChunkAccess`, `RegionalApi.getRegionRawId`, and `CommonRegionMovementTracker` now operate on 100% homogeneous chunks in O(1) time, eliminating sub-chunk border polling on `ServerPlayer` ticks.
* UPDATED: `MixinChunkSerializer` writes all chunks using the compact 3-byte homogeneous NBT tag (`bytes[0] = 1` + `short` region ID) and automatically upgrades legacy 33-byte border NBT tags from existing worlds on chunk read.

--- [VERSION 1.0.10] ---
* ADDED: Region-constrained biome discovery via `/locate region <region_id> biome <biome_id | #biome_tag>` with full vanilla/modded biome and tag tab-completion (`ResourceOrTagArgument`).
* ADDED: Region-constrained structure discovery via `/locate region <region_id> structure <structure_id | #structure_tag>` with full vanilla/modded structure and tag tab-completion (`ResourceOrTagKeyArgument`).
* ADDED: `com.regionalapi.core.search.RegionSpatialLocator` providing Zero-GC O(1) region pre-filtering via `ThreadLocalRegionCache`, 3D `BiomeMaskRule` fail-fast & elevation-aware sampling, asynchronous worker offloading (`Util.backgroundExecutor()`), and bounded main-thread `StructureManager` / `ChunkStatus.STRUCTURE_STARTS` verification across `INFINITE_TESSELLATION`, `FINITE_CENTRALIZED`, and `isUnique == true` QuadTree regions.
* FIXED: Nearest region ring search now begins at ring `r = 0` (checking the origin's own Voronoi cell) and resolves `regionalapi:wilds` boundary points under `FINITE_CENTRALIZED` mode.
* UPDATED: `LocateRegionCommand.register` now accepts `CommandBuildContext` and is synchronized atomically across `:common`, `:neoforge`, `:fabric`, and `:forge`.
* UPDATED: Added English localization keys (`commands.locate.region.biome.*`, `commands.locate.region.structure.*`) in `en_us.json`.

--- [VERSION 1.0.11] ---
* ADDED: `com.regionalapi.core.region.RegionContentRegistry` — optional, thread-safe declarative metadata registry allowing addons to associate biome IDs, biome tags, structure IDs, and structure tags with regions for inter-addon introspection with zero worldgen hot-path overhead.
* ADDED: Public `RegionalApi` registration and introspection methods (`registerRegionBiome`, `registerRegionBiomes`, `registerRegionBiomeTag`, `registerRegionBiomeTags`, `registerRegionStructure`, `registerRegionStructures`, `registerRegionStructureTag`, `registerRegionStructureTags`, `getRegisteredRegionBiomes`, `getRegisteredRegionBiomeTags`, `hasRegisteredRegionBiomes`, `getRegisteredRegionStructures`, `getRegisteredRegionStructureTags`, `hasRegisteredRegionStructures`, `isBiomeRegisteredForRegion`, `isStructureRegisteredForRegion`) — 100% optional and backward-compatible.
* UPDATED: `LocateRegionCommand` now provides server-authoritative region-scoped tab-completion:
  - `/locate region <region> structure` suggests exclusively the structures and tags registered to `<region>` when present, falling back to global `Registries.STRUCTURE` otherwise.
  - `/locate region <region> biome` suggests exclusively the region's biomes/tags when explicitly registered or when constrained by a dual `BiomeMaskRule` (both surface and cave overrides set), falling back to global `Registries.BIOME` otherwise.
* FIXED: `RegionSpatialLocator#locateStructureInRegion` now executes full vanilla-exact ring-by-ring (`r = 0 .. 100`) chunk verification via `StructureManager#checkStructurePresence` and `ChunkStatus.STRUCTURE_STARTS` with O(1) RegionalAPI chunk pre-filtering and ring-level early exit, removing artificial candidate/chunk-load/time truncation caps that caused rare biome-specific structures (such as `minecraft:village_desert`) to return false negatives.
